## 🚀 Overview  
Speech recognition is a critical task in voice technology, yet **low-resource languages like Persian lack high-quality datasets**. PAZHVAK is the **first public Persian word-level ASR dataset**, containing:  
- 88,535 audio files  
- 4,018 common Persian words  
- Recorded by 61 students (38 male, 23 female) at University of Hormozgan  


## 🔍 Key Features  
- 📖 **4,018-word vocabulary** classification  
- 🤖 **Open-source** pretrained models
